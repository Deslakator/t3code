# Диктовка через OpenRouter на Mac

Диктовка принадлежит Mac-приложению и не зависит от выбранного environment.
Микрофон записывается в интерфейсе; основной процесс Electron отправляет запись
напрямую в OpenRouter. Локальный и удалённые T3-серверы не получают ни аудио,
ни ключ OpenRouter. Результат вставляется в текущий черновик.

## Настройка

Установите Mac-сборку форка с поддержкой диктовки. Откройте
**Settings → General → Audio · OpenRouter dictation**:

1. Вставьте ключ OpenRouter в поле **OpenRouter API key**.
2. Укажите модель транскрибации. По умолчанию — `openai/whisper-large-v3-turbo`.
   Обычная текстовая chat-модель для этого endpoint не подходит.
3. Включите **Enable dictation** и нажмите **Save audio settings**.

Настройки применяются сразу, без перезапуска и независимо от выбранного сервера.
Ключ сохраняется через Electron safeStorage в зашифрованном виде, в файле
`audio-settings.json` рядом с desktop-файлом `client-settings.json`. Расшифровка
зависит от защищённого хранилища macOS; не переносите зашифрованный файл между
машинами в расчёте на сохранение доступа к ключу.

Сохранённый ключ не возвращается в интерфейс. Пустое поле при сохранении означает
«оставить существующий ключ». Чтобы заменить ключ, введите новый и сохраните.
**Remove key** удаляет ключ и выключает диктовку. Для временного отключения
снимите Enable dictation и сохраните настройки.

Не присылайте ключ в чат, не храните его в исходниках или server `.env`.
Серверный `dictation.json` больше не используется. Старую серверную конфигурацию
можно удалить вручную после перехода, если вы ранее её создавали.

## Использование

Нажмите микрофон в основном поле сообщения. При первом запуске разрешите доступ
в macOS. Повторное нажатие останавливает запись и запускает распознавание.
Запрос оплачивается с баланса вашего OpenRouter. Язык фиксирован как `ru`:
русская речь с английскими техническими терминами, независимо от языка интерфейса.

Текст вставляется с пунктуацией распознавателя. Дополнительной редакторской
обработки и перевода нет. Сообщение агенту автоматически не отправляется.
Во время записи и распознавания отправка сообщения заблокирована, но текст можно
редактировать. Если черновик изменился, результат показывается отдельно для
копирования, а не вставляется поверх изменений.

Отмена прекращает запись/ожидание и прерывает исходящий запрос, где это возможно.
Уже обработанный провайдером запрос всё равно может быть оплачен. Автоматических
повторов платного запроса нет. Переключение чата и уход приложения в фон отменяют
операцию и освобождают микрофон.

## Ограничения

- Первый этап — только macOS desktop. В браузере и на iPhone кнопки нет.
- До пяти минут; PCM16 mono WAV 16 kHz, максимум 9 600 044 байт.
- Передача из renderer в Electron блоками до 48 000 байт, без большого IPC-пакета.
- Одна активная операция на окно; до четырёх загрузок на приложение.
- Заброшенные загрузки очищаются примерно через 10–11 минут; аудио не сохраняется
  в историю чата, вложения или файлы этим модулем.
- Таймаут OpenRouter — 60 секунд. Точность русских/английских терминов и время
  ответа нужно проверить на реальных записях.
- Если запись недоступна: macOS System Settings → Privacy & Security → Microphone.
  После изменения системного разрешения может потребоваться перезапуск приложения.
- При отказе secure storage настройки с новым ключом не сохраняются открытым текстом.

Сборка Mac: `vp run dist:desktop:dmg:arm64`, результат в `release/`.
Сервер обновлять или настраивать для диктовки не нужно.

API: https://openrouter.ai/docs/api/api-reference/stt/create-transcription
